
# Tuiana Design — сайт студии

**Сайт:** https://tuiana.ru/

Многостраничный сайт Tuiana Design, посвящённый веб-дизайну, созданию цифровых продуктов, презентаций и AI-креативу.

Проект разработан с использованием OpenCode и AI-инструментов.

## Задача

Создать сайт, на котором потенциальные клиенты смогут познакомиться с услугами студии, посмотреть выполненные проекты и связаться для обсуждения заказа.

Особое внимание уделено структуре информации, визуальному оформлению и удобству просмотра на разных устройствах.

## Что реализовано

- Главная страница с описанием направлений работы.
- Разделы услуг и стоимости.
- Портфолио с отдельными страницами проектов.
- Кейсы «ДАРИ», «Наша База» и другие работы.
- Страница о создании мини-сайтов на Taplink.
- Информация о специалисте и образовании.
- Отзывы, контакты и способы связи.
- Адаптивный интерфейс.
- Страницы с юридической информацией.

## Технологии

- React — создание компонентов интерфейса.
- TypeScript — логика приложения.
- CSS — оформление и адаптивность.
- React Router — переходы между страницами.
- Vite — сборка проекта.
- Git и GitHub — управление версиями.
- OpenCode — AI-помощник при разработке.

## Структура проекта

- `src/` — компоненты, страницы, стили и логика.
- `public/` — изображения и другие статические материалы.
- `scripts/` — вспомогательные сценарии сборки.
- `.github/workflows/` — автоматическая публикация сайта.

## Локальный запуск

Установка зависимостей:

`npm ci`

Запуск проекта:

`npm run dev`

Проверка сборки:

`npm run build`

## Публикация

Сайт публикуется через GitHub Actions и GitHub Pages.

Рабочая ветка: `system-section`.

Адрес опубликованного сайта: https://tuiana.ru/
